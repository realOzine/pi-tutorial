## 真实 OpenAI 验证

本轮按用户指定模型 `gpt-6.1-terra` 实际请求 OpenAI Responses，reasoning effort 为 `none`。总计 7 次请求，返回 usage 合计 1,912 input tokens、214 output tokens。分项如下：

| 实验 | 请求次数 | Input / output tokens | 结论 |
|---|---:|---:|---|
| 短连接探测 | 1 | 11 / 5 | API 接口和该模型可用 |
| 第 03 课最小 MVP | 2 | 219 / 26 | 模型请求读取、接收工具结果后回答 |
| 第 12 课流式毕业项目 | 4 | 1,682 / 183 | 模型实际修复文件；停止后由新进程恢复，检查与回答完成 |

毕业项目收到 107 次 preview 事件；恢复后 `check_file` 返回 `exitCode=0`，最终文件通过独立精确内容与语法验收，`edit_file` 总共执行一次。这个样例验证了当前配置下的一条完整路径，不证明所有任务都能成功，也不证明任意崩溃后副作用只发生一次。

按核验时官方标准输入与输出单价粗估，以上总费用约 **$0.003**；这是基于 usage 的估算，不是账单实扣，也没有按缓存等计费细项调整。价格依据为 [OpenAI 模型页](https://developers.openai.com/api/docs/models/gpt-6.1-terra)。具体配置、限制与运行记录见 [真实模型验证](live-verification.md)。

本地产物在被 Git 忽略的 `artifacts/`：`api-probe.json`、`live-mvp.json`、`live-mvp-calls.json` 与 `live-capstone/` 下的会话和运行记录。凭据不纳入产物或 Git；未知 usage 保留未知，不能当成零成本。
